# Rethinking case attraction on Ancient Greek infinitive clauses

**Caio B. A. Geraldes** <[caio.geraldes@usp.br](mailto:caio.geraldes@usp.br)>

This repository contains the source code for my talk at the International
Colloquium of Ancient Greek Linguistics - 2025 (Nice).

The data and scripts for the statistical models and DAGs is placed under the
fold _analysis_.
It depends on above all on the packages
[rethinking](https://github.com/rmcelreath/rethinking).
If you would like to reproduce the results and tweak with the code and data,
check its documentation (it is sometimes a bit tricky to make it work properly,
specially on Apple's M1 processors).
The dataset is in csv and will be refined in the next months before it is fit
for publication, but feel free to explore it.

The remaining folders are all dedicated for the presentation itself, with self
explaining names. 

For the updated _release_ version, check the 
[Releases](https://github.com/caiogeraldes/icagl2025/releases/), it will 
contain all the pdfs, the compiled Rnotebook, the source code for the analysis 
and the data.

If you would like to cite any part contained in this repository, please cite the
abstract in the book of abstracts.
